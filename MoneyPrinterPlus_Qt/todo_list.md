## 开发指南

### 环境设置
```bash
cd MoneyPrinterPlus_Qt
pip install -r requirements_qt.txt
```

### 运行和测试
```bash
# 核心功能测试
python simple_test.py

# 启动应用
python main.py

# 启动测试（自动关闭）
python test_startup.py
```

### 代码规范
- 使用Python 3.8+ 语法
- 遵循PEP 8代码规范
- 组件间松耦合设计
- 统一错误处理机制

### UI设计原则 ⚠️
**重要提醒：避免可见性问题**
- **文字对比度检查**：确保文字与背景色有足够对比度（至少4.5:1）
- **测试不同状态**：检查文字在正常、悬停、选中状态下的可见性
- **避免白色文字**：谨慎使用白色文字，确保背景足够深色
- **实际测试优先**：UI修改后必须进行实际显示效果测试
- **多种环境验证**：在不同显示器和DPI设置下验证显示效果
- **颜色搭配参考**：
  - 深色背景 (#2c3e50) + 纯白文字 (#ffffff) ✅
  - 浅色背景 (#f8f9fa) + 深色文字 (#212529) ✅  
  - 避免：浅色背景 + 浅色文字 ❌
  - 避免：深色背景 + 深色文字 ❌

### AI服务集成原则 ⚠️
**重要要求：只使用真实API调用**
- **禁止模拟模式**：不提供任何模拟或假数据生成功能
- **真实调用优先**：所有AI功能必须调用真实的API服务
- **错误透明化**：配置错误或API调用失败时直接显示真实错误信息
- **配置强制性**：用户必须正确配置API密钥才能使用AI功能
- **无后备方案**：不提供模拟、示例或占位内容作为后备方案
